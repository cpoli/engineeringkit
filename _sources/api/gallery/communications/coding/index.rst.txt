In the (7,4) code three parity bits sit at positions 1, 2 and 4. When one bit flips, the failing parity checks, read as a binary number, give its position (~engineeringkit.communications.hamming74_encode, hamming74_decode). Any two codewords differ in at least three places (~engineeringkit.communications.hamming_distance), which is what makes single-error correction possible.">
