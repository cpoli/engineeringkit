.. raw:: html

    <div class="sphx-glr-thumbcontainer" tooltip="James Watt&#x27;s flyball governor (1788) closed the steam valve as the engine sped up: the throttle moved in proportion to the speed error. Model the engine as J\dot\omega = \tau - b\omega - \tau_{load} and the governor as \tau = K_p(\omega_{ref} - \omega), a proportional PID. A proportional governor holds speed far better than an open throttle, but it always leaves a steady droop, \Delta\omega = \tau_{load}/(b + K_p), which shrinks with gain but never vanishes.">

His three-term controller, \delta = K_p e + K_i \int e\,dt + K_d \dot e, is the PID. Using Nomoto&#x27;s ship model \psi/\delta = K/(s(Ts + 1)) and a steady wind moment, proportional plus derivative action leaves a constant heading offset d/K_p; adding integral action removes it.">

With a huge open-loop gain A, the closed-loop gain A/(1 + A\beta) (~engineeringkit.control_systems.feedback) is almost exactly 1/\beta, set by a passive divider rather than by drifting vacuum tubes. Distortion and gain variations shrink by the factor 1 + A\beta, and the bandwidth grows by the same factor.">
