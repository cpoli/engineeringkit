Examples
========

.. include:: /_generated/nav/control_systems.rst

This gallery walks through every public feature of
``engineeringkit.control_systems``, one breakthrough per script: feedback
and PID control, algebraic and Lyapunov stability tests, frequency-response
design, transient specifications, the root locus, sampled-data control,
state-space design and optimal control and estimation.

:doc:`Units, assumptions and numerical validation </guides/control_systems>`
gives the validity limits. Each script is self-contained and can be run
directly with ``python examples/control_systems/<section>/<script>.py``.

Sections
--------

- **feedback** -- Watt's governor, Minorsky's PID, Black's feedback amplifier and Ziegler-Nichols tuning.
- **stability** -- Maxwell's characteristic roots, Routh's array, Lyapunov's direct method and Hurwitz's determinants.
- **frequency** -- Nyquist's criterion and Bode's stability margins.
- **time_response** -- Hazen's second-order servomechanism.
- **root_locus** -- Evans's root locus.
- **sampled** -- Ragazzini and Zadeh's zero-order-hold discretisation.
- **state_space** -- Kalman's controllability, Luenberger's observer and Wonham's pole placement.
- **optimal** -- Bellman's dynamic programming, Kalman's LQR and the Kalman-Bucy filter.

.. raw:: html

    <div class="sphx-glr-thumbcontainer" tooltip="James Watt&#x27;s flyball governor (1788) closed the steam valve as the engine sped up: the throttle moved in proportion to the speed error. Model the engine as J\dot\omega = \tau - b\omega - \tau_{load} and the governor as \tau = K_p(\omega_{ref} - \omega), a proportional PID. A proportional governor holds speed far better than an open throttle, but it always leaves a steady droop, \Delta\omega = \tau_{load}/(b + K_p), which shrinks with gain but never vanishes.">

    <div class="sphx-glr-thumbcontainer" tooltip="Long-distance telephone repeaters with feedback sometimes &quot;sang&quot;. Harry Nyquist (1932) showed how to predict this from the measured open-loop frequency response alone. Trace L(j\omega) for all frequencies (~engineeringkit.control_systems.nyquist): the closed loop has Z = N + P unstable poles, where N counts clockwise encirclements of -1 (~engineeringkit.control_systems.nyquist_encirclements) and P the unstable open-loop poles.">

Stability
---------

Characteristic roots, the Routh and Hurwitz tests and Lyapunov functions.


.. raw:: html

  <div id='sg-tag-list' class='sphx-glr-tag-list'></div>


.. raw:: html

    <div class="sphx-glr-thumbnails">

.. thumbnail-parent-div-open

.. raw:: html

    <div class="sphx-glr-thumbcontainer" tooltip="Governors fitted with integral action to remove droop sometimes &quot;hunted&quot;, oscillating with growing amplitude. James Clerk Maxwell (1868) linearised the engine-governor equations and showed that motion is stable exactly when every root of the characteristic polynomial has a negative real part (~engineeringkit.control_systems.poles). For the cubic s^3 + a_1 s^2 + a_2 s + a_3 he found the condition a_1 a_2 &gt; a_3: too much integral gain destabilises the governor.">

  .. image:: /api/gallery/control_systems/stability/images/thumb/sphx_glr_plot_01_maxwell_on_governors_thumb.png

    </div>


.. raw:: html

    <div class="sphx-glr-thumbcontainer" tooltip="Maxwell could not state a test for polynomials above fourth order. Edward Routh&#x27;s Adams Prize essay (1877) solved the problem with a table built from the coefficients alone: the number of sign changes down its first column (~engineeringkit.control_systems.routh_first_column) equals the number of roots in the right half-plane. For the closed loop of K/(s(s+1)(s+2)), s^3 + 3s^2 + 2s + K, the table shows the loop is stable only for 0 &lt; K &lt; 6.">

.. raw:: html

    <div class="sphx-glr-thumbcontainer" tooltip="Aleksandr Lyapunov&#x27;s doctoral thesis (1892) proved stability without solving the equations of motion. Find an energy-like function V(x) &gt; 0 that decreases along every trajectory, and the equilibrium is stable. For linear dynamics \dot x = Ax, the quadratic V = x^\mathsf{T} P x works exactly when the Lyapunov equation A^\mathsf{T}P + PA = -Q has a positive definite solution (~engineeringkit.control_systems.lyapunov_equation, lyapunov_stable).">
