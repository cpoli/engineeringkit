Sampled-data control
--------------------

Computer control with a zero-order hold or Tustin's transform, and stability inside the unit circle.

.. raw:: html

    <div class="sphx-glr-thumbcontainer" tooltip="When a digital computer closes the loop it reads the plant only at sampling instants and holds each command constant until the next. John Ragazzini and Lotfi Zadeh (1952) developed the z-transform analysis of such loops. For a zero-order hold the continuous model is replaced exactly by x_{k+1} = e^{AT}x_k + \int_0^T e^{A\tau}d\tau\,B\,u_k (~engineeringkit.control_systems.discretize_zoh). The naive Euler step x_{k+1} = (I + AT)x_k + BTu_k is only an approximation.">

Eliahu Jury (1961) gave the discrete counterpart: a table that reduces the polynomial one degree at a time and checks |a_n| &lt; |a_0| at each step, with no roots computed (~engineeringkit.control_systems.jury_stable).">

.. raw:: html

    <div class="sphx-glr-thumbcontainer" tooltip="Arnold Tustin, analysing servomechanisms at Metropolitan-Vickers, turned continuous dynamics into recurrences on sampled values by substituting s \to (2/T)(z - 1)/(z + 1), which integrates by the trapezoidal rule (~engineeringkit.control_systems.discretize_tustin). The whole left half-plane maps into the unit disc, so a stable model stays stable, but the frequency axis is compressed: a continuous frequency \omega appears at (2/T)\arctan(\omega T/2). A sharp resonance near the Nyquist frequency moves. Prewarping, substituting \omega_0/\tan(\omega_0T/2) for 2/T, puts it back exactly at \omega_0.">
