.. raw:: html

    <div class="sphx-glr-thumbcontainer" tooltip="A transfer function describes only the part of a system that the input reaches and the output sees. Rudolf Kalman (1960) split the state into these parts. The state of \dot x = Ax + Bu can be steered anywhere only if the controllability matrix [B, AB, \dots, A^{n-1}B] has full rank, and reconstructed from y = Cx only if the observability matrix [C; CA; \dots; CA^{n-1}] does (~engineeringkit.control_systems.is_controllable, is_observable). A mode that fails either test disappears from the transfer function in a pole-zero cancellation, but it is still there.">

.. raw:: html

    <div class="sphx-glr-thumbcontainer" tooltip="State feedback needs every state, but sensors measure only some of them. David Luenberger (1964) built the missing states from a copy of the model driven by the same input and corrected by the output error, \dot{\hat x} = A\hat x + Bu + L(y - C\hat x). The estimation error e = x - \hat x then obeys \dot e = (A - LC)e whatever the input, and if (A, C) is observable the gain L places those error poles anywhere (~engineeringkit.control_systems.observer_gain).">

Murray Wonham (1967) proved that the same holds with several inputs: the closed-loop poles can be assigned arbitrarily if and only if (A, B) is controllable, even when no single input could do it (~engineeringkit.control_systems.state_feedback_poles). A precompensator N then scales the reference so the output settles on it (~engineeringkit.control_systems.feedforward_gain).">
