    <div class="sphx-glr-thumbcontainer" tooltip="In 1868 William Froude proposed to the Admiralty that a ship&#x27;s resistance could be predicted from towing a small model, if the model ran at the &quot;corresponding speed&quot;, v_m = v_s\sqrt{L_m/L_s}. Then the waves the two make have the same shape, because the Froude number Fr = v/\sqrt{gL} (~engineeringkit.fluid_engineering.froude_number) is the same. Skin friction does not scale that way, so Froude split the resistance: friction from flat-plank tests, the rest scaled with the displacement. His tank at Torquay checked the method against full-scale towing of HMS Greyhound in 1871. This example scales a model test to a ship, using the ITTC 1957 friction line in place of Froude&#x27;s planks.">

The products are the null space of the dimension matrix, which buckingham_pi finds by exact row reduction. This example derives the groups of pipe friction and of droplet break-up, then shows that pipes of different size and fluid with the same groups have the same Euler number (~engineeringkit.fluid_engineering.euler_number).">
