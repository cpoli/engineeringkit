engineeringkit.control_systems#

Domain hub · History · Examples · API reference

Classical stability, PID responses, state feedback, LQR and estimation.

engineeringkit.control_systems: feedback, stability, frequency response, state space and optimal control.

Black’s feedback amplifier and Minorsky’s PID controller with Ziegler-Nichols tuning; Maxwell’s characteristic roots, the Routh and Hurwitz tests and Lyapunov’s direct method; Nyquist’s encirclement criterion, Bode plots and stability margins; Evans’s root locus; Hazen’s second-order servo specifications; Padé dead-time approximation and Smith’s predictor; zero-order-hold discretisation and Jury’s test; Kalman’s controllability and observability, pole placement and Luenberger observers; and the LQR, discrete LQR and Kalman-Bucy Riccati designs. Models are continuous-time and SISO unless stated; SciPy supplies the LTI objects, Riccati/Lyapunov solvers, pole placement and step responses.

Ideal parallel PID controller \(C(s) = K_p + K_i/s + K_d s\).

Derivative action is ideal (no roll-off filter), and there is no actuator saturation or anti-windup. With ki == 0 no integrator is included.

engineeringkit.control_systems.dlqr(A, B, Q, R)[source]#

Discrete-time infinite-horizon linear-quadratic regulator.

Minimises \(\sum_{k \ge 0} (x_k^\mathsf{T} Q x_k + u_k^\mathsf{T} R u_k)\) over \(u_k = -K x_k\) for \(x_{k+1} = A x_k + B u_k\); the steady state of Bellman’s backward dynamic-programming recursion.

Parameters:

  • A (array_like) – Discrete state matrix, shape (n, n).

  • B (array_like) – Discrete input matrix, shape (n, m).

  • Q (array_like) – Symmetric positive semidefinite state weight, shape (n, n).

  • R (array_like) – Symmetric positive definite input weight, shape (m, m).

Returns:

(K, P, poles): gain \(K = (R + B^\mathsf{T}PB)^{-1}B^\mathsf{T}PA\), the discrete Riccati solution \(P\) and the closed-loop eigenvalues (inside the unit circle when stabilising).

Return type:

tuple

Notes

See Control systems: matrix contracts and numerical stability.

References

  1. Bellman, Dynamic Programming (Princeton University Press, 1957).

Examples

>>> K, P, poles = dlqr([[1.0]], [[1.0]], [[1.0]], [[1.0]])
>>> round(float(P[0, 0]), 6), round(float(K[0, 0]), 6)
(1.618034, 0.618034)

engineeringkit.control_systems.hurwitz_determinants(coeffs)[source]#

Leading principal minors \(\Delta_1, \dots, \Delta_n\) of the Hurwitz matrix.

For \(a_0 s^n + a_1 s^{n-1} + \dots + a_n\) with \(a_0 > 0\), all roots lie in the open left half-plane if and only if every \(\Delta_k > 0\). The Hurwitz matrix has entries \(H_{ij} = a_{2j-i}\) (1-based, \(a_k = 0\) outside \(0 \le k \le n\)).

Parameters:

coeffs (array_like) – Real coefficients in descending powers of \(s\), degree at least one. They are normalised by the leading coefficient.

Returns:

The \(n\) determinants.

Return type:

ndarray

Notes

On the stability boundary \(\Delta_{n-1} = 0\) (a pair of imaginary roots) or \(\Delta_n = 0\) (a root at the origin). See Control systems: matrix contracts and numerical stability.

References

A. Hurwitz, “Ueber die Bedingungen, unter welchen eine Gleichung nur Wurzeln mit negativen reellen Theilen besitzt,” Math. Ann. 46 (1895) 273-284.

Examples

>>> hurwitz_determinants([1, 3, 3, 1]).round(6).tolist()
[3.0, 8.0, 8.0]

engineeringkit.control_systems.jury_stable(coeffs)[source]#

Whether every root of a polynomial in \(z\) lies strictly inside the unit circle.

Jury’s table reduces \(P(z) = a_0 z^n + a_1 z^{n-1} + \dots + a_n\) one degree at a time. Each row is \(a_0 P(z) - a_n z^n P(1/z)\), divided by \(z\), and the polynomial is stable if and only if \(|a_n| < |a_0|\) holds at every step down to degree zero.

Parameters:

coeffs (array_like) – Real coefficients in descending powers of \(z\), degree at least one.

Returns:

True if all roots satisfy \(|z| < 1\); roots on the unit circle count as unstable.

Return type:

bool

Notes

This is the discrete counterpart of Routh’s test: no roots are computed. The quick necessary conditions \(P(1) > 0\) and \((-1)^n P(-1) > 0\) (for \(a_0 > 0\)) follow from it. Each row is normalised to unit leading coefficient, and a relative tolerance of \(10^{-12}\) decides the boundary cases. See Control systems: matrix contracts and numerical stability.

References

E. I. Jury and J. Blanchard, “A stability test for linear discrete systems in table form,” Proc. IRE 49 (1961) 1947-1948.

Examples

>>> jury_stable([1, -1.0, 0.5]), jury_stable([1, -2.5, 1.0])
(True, False)
engineeringkit.control_systems.kalman_gain(A, C, Q, R)[source]#

Steady-state Kalman-Bucy estimator gain for continuous-time measurements.

For \(\dot x = Ax + w\), \(y = Cx + v\) with white process and measurement noise of spectral densities \(Q\) and \(R\), the estimator \(\dot{\hat x} = A\hat x + L(y - C\hat x)\) with \(L = PC^\mathsf{T}R^{-1}\) minimises the steady error covariance \(P\).

Parameters:

  • A (array_like) – State matrix, shape (n, n) [1/s].

  • C (array_like) – Output matrix, shape (p, n).

  • Q (array_like) – Process-noise spectral density, symmetric positive semidefinite, shape (n, n).

  • R (array_like) – Measurement-noise spectral density, symmetric positive definite, shape (p, p).

Returns:

(L, P, poles): observer gain, error covariance and estimator poles [1/s].

Return type:

tuple

Notes

\(P\) solves \(AP + PA^\mathsf{T} - PC^\mathsf{T}R^{-1}CP + Q = 0\). \(Q\) and \(R\) are spectral densities, not sampled covariances. See Control systems: matrix contracts and numerical stability.

References

R. E. Kalman and R. S. Bucy, “New results in linear filtering and prediction theory,” J. Basic Eng. 83 (1961) 95-108.

Examples

>>> L, P, poles = kalman_gain([[0]], [[1]], [[4]], [[1]])
>>> L.round(6).tolist(), P.round(6).tolist()
([[2.0]], [[2.0]])
engineeringkit.control_systems.lqr(A, B, Q, R)[source]#

Continuous-time linear-quadratic regulator.

Minimises \(J = \int_0^\infty (x^\mathsf{T} Q x + u^\mathsf{T} R u)\,dt\) over \(u = -Kx\) for \(\dot x = Ax + Bu\).

Parameters:

  • A (array_like) – State matrix, shape (n, n) [1/s].

  • B (array_like) – Input matrix, shape (n, m).

  • Q (array_like) – Symmetric positive semidefinite state weight, shape (n, n).

  • R (array_like) – Symmetric positive definite input weight, shape (m, m).

Returns:

(K, P, poles): gain \(K = R^{-1} B^\mathsf{T} P\), the Riccati solution \(P\) (so the optimal cost from \(x_0\) is \(x_0^\mathsf{T} P x_0\)) and the closed-loop poles [1/s].

Return type:

tuple

Notes

\(P\) solves \(A^\mathsf{T}P + PA - PBR^{-1}B^\mathsf{T}P + Q = 0\). A stabilising solution needs \((A, B)\) stabilisable and \((Q^{1/2}, A)\) detectable; SciPy errors are not masked. See Control systems: matrix contracts and numerical stability.

References

R. E. Kalman, “Contributions to the theory of optimal control,” Bol. Soc. Mat. Mexicana 5 (1960) 102-119.

Examples

>>> K, P, poles = lqr([[0]], [[1]], [[4]], [[1]])
>>> K.round(6).tolist(), poles.real.round(6).tolist()
([[2.0]], [-2.0])
engineeringkit.control_systems.lyapunov_equation(A, Q=None)[source]#

Solve the continuous Lyapunov equation \(A^\mathsf{T} P + P A = -Q\).

If \(A\) is stable, \(V(x) = x^\mathsf{T} P x\) is a Lyapunov function: it is positive and decreases at the rate \(\dot V = -x^\mathsf{T} Q x\) along every trajectory of \(\dot x = Ax\).

Parameters:

  • Q (array_like, optional) – Symmetric positive semidefinite decay-rate matrix, shape (n, n); the identity by default.

Returns:

Symmetric solution \(P\).

Return type:

ndarray

Raises:

ValueError – If two eigenvalues of \(A\) sum to zero, so the equation has no unique solution.

Notes

See Control systems: matrix contracts and numerical stability.

References

A. M. Lyapunov, The General Problem of the Stability of Motion (Kharkov, 1892; English translation, Taylor & Francis, 1992).

engineeringkit.control_systems.nyquist_encirclements(sys, w=None)[source]#

Net clockwise encirclements of \(-1\) by the Nyquist plot of a loop.

Nyquist’s criterion: the closed loop \(L/(1+L)\) has \(Z = N + P\) right-half-plane poles, where \(P\) is the number of open-loop right-half-plane poles and \(N\) the value returned here.

Parameters:

  • sys (scipy.signal.lti) – Proper open-loop model \(L(s)\) with no poles on the imaginary axis.

  • w (array_like, optional) – Positive angular frequencies [rad/s] spanning all features of \(L\); defaults to 40001 points from \(10^{-4}\) to \(10^4\).

Returns:

Clockwise encirclements of \(-1\) (negative if counter-clockwise).

Return type:

int

Raises:

ValueError – If \(L\) is improper, has imaginary-axis poles, or passes through \(-1\) on the grid.

Notes

The plot is traced for \(\omega\) from \(-\infty\) to \(\infty\); for a proper loop the infinite semicircle maps to a single point. A grid that misses a fast phase swing can miscount. See Control systems: matrix contracts and numerical stability.

References

H. Nyquist, “Regeneration theory,” Bell Syst. Tech. J. 11 (1932) 126-147.

Examples

>>> from engineeringkit.control_systems import transfer_function
>>> nyquist_encirclements(transfer_function([12], [1, 3, 3, 1]))

engineeringkit.control_systems.pade_delay(delay, order=1)[source]#

Diagonal Padé approximant of a time delay \(e^{-s\theta}\).

Parameters:

  • delay (float) – Dead time \(\theta\) [s], positive.

  • order (int, optional) – Degree \(n \ge 1\) of numerator and denominator.

Returns:

\(D(-s)/D(s)\) with \(D(s) = \sum_{k=0}^{n} \frac{(2n-k)!\,n!}{(2n)!\,k!\,(n-k)!}(s\theta)^k\).

Return type:

scipy.signal.TransferFunction

Notes

The approximant is all-pass, \(|D(-j\omega)/D(j\omega)| = 1\), and matches the Taylor series of \(e^{-s\theta}\) to order \(2n\), so its phase is accurate for \(\omega\theta\) up to about \(n\). It has \(n\) right-half-plane zeros, so its step response starts with an undershoot that the true delay does not have. See Control systems: matrix contracts and numerical stability.

References

H. Padé, “Sur la représentation approchée d’une fonction par des fractions rationnelles,” Ann. Sci. École Norm. Sup. 9 (1892) 3-93.

Examples

>>> D = pade_delay(2.0)
>>> D.num.tolist(), D.den.tolist()
([-1.0, 1.0], [1.0, 1.0])

engineeringkit.control_systems.smith_predictor(controller, plant, delay, order=3)[source]#

Equivalent controller of a Smith predictor around a delayed plant.

The plant is \(G(s)e^{-s\theta}\). The predictor feeds back the output of a delay-free model \(G\) and corrects it by the difference between the measured output and the delayed model output. The result is the single controller

\[C_{\mathrm{SP}} = \frac{C}{1 + C G\,(1 - e^{-s\theta})},\]

which makes the closed loop \(CGe^{-s\theta}/(1 + CG)\): the delay-free design, delayed.

Parameters:

  • controller (scipy.signal.lti) – Primary controller \(C(s)\), designed for the delay-free plant.

  • plant (scipy.signal.lti) – Delay-free plant model \(G(s)\).

  • delay (float) – Dead time \(\theta\) [s], positive.

  • order (int, optional) – Padé order used for the delay inside the predictor.

Returns:

\(C_{\mathrm{SP}}(s)\) with \(e^{-s\theta}\) replaced by pade_delay() of the given order.

Return type:

scipy.signal.TransferFunction

Notes

The predictor relies on a perfect model: mismatch in \(G\) or \(\theta\) reappears in the characteristic equation. It cannot stabilise an unstable plant, whose mode stays in the open loop. In a computer the delay is a buffer of past commands, not a Padé factor. See Control systems: matrix contracts and numerical stability.

References

O. J. M. Smith, “Closer control of loops with dead time,” Chem. Eng. Prog. 53 (1957) 217-219.

Examples

>>> from engineeringkit.control_systems import transfer_function
>>> Csp = smith_predictor(transfer_function([1], [1]), transfer_function([1], [1, 1]), 1.0, order=1)
>>> Csp.num.tolist(), Csp.den.tolist()
([1.0, 3.0, 2.0], [1.0, 5.0, 2.0])
engineeringkit.control_systems.stability_margins(sys, w=None)[source]#

Worst gain and phase margins over all crossovers of a loop’s frequency response.

Parameters:

  • sys (scipy.signal.lti) – SISO open-loop model \(L(s)\).

  • w (array_like, optional) – Positive angular frequencies [rad/s]; defaults to 20000 points from \(10^{-4}\) to \(10^4\).

Returns:

gain_margin [-], the margin at the phase crossover nearest instability (inf without a phase crossover); phase_margin_deg [deg], the margin of smallest magnitude over the gain crossovers (nan without one); gain_cross_frequency and phase_cross_frequency [rad/s], the crossovers at which those worst margins are read (nan if absent); and the arrays phase_cross_frequencies [rad/s] with their gain_margins [-], and gain_cross_frequencies [rad/s] with their phase_margins_deg [deg], over every crossover in increasing frequency.

Return type:

dict

Notes

A phase crossover is any frequency where the phase passes \(-180^\circ + 360^\circ k\). Its gain margin \(1/|L(j\omega)|\) is below one when reducing the gain by that factor reaches instability, as in a conditionally stable loop; the worst gain margin is the one with the smallest \(|\log \mathrm{GM}|\). Phase margins are wrapped into \([-180^\circ, 180^\circ)\); a negative one means the plot crosses the unit circle on the far side of \(-1\), and a phase lead of that size reaches instability. With one crossover and a stable open loop that signals an unstable closed loop, but an open-loop unstable loop that needs counter-clockwise encirclements can cross on both sides, so the worst phase margin is the one of smallest magnitude. Crossings are interpolated linearly in log-frequency between grid points, so a grid that misses a crossover misses its margin. Time delays need a rational approximation such as pade_delay(). See Control systems: matrix contracts and numerical stability.

References

H. W. Bode, “Relations between attenuation and phase in feedback amplifier design,” Bell Syst. Tech. J. 19 (1940) 421-454.

Examples

>>> from engineeringkit.control_systems import transfer_function
>>> m = stability_margins(transfer_function([2], [1, 3, 2, 0]))
>>> round(m["gain_margin"], 2), round(m["phase_cross_frequency"], 3)
(3.0, 1.414)
