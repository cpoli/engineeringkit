engineeringkit.electrical_engineering#

Domain hub · History · Examples · API reference

Ohm’s law, series and parallel equivalents, the Wheatstone bridge and modified nodal analysis; Thévenin and Norton equivalents and maximum power transfer; RC and RL transients; phasors, complex impedance, series resonance and the ideal transformer; lossless and lossy transmission lines, the distortionless condition, reflection coefficients and input impedance; real, reactive and three-phase power, symmetrical components and Gauss-Seidel load flow (linear systems by numpy.linalg, the RLC step response by scipy.signal).

engineeringkit.electrical_engineering: circuits from Ohm’s law to the digital load flow.

Ohm’s law, series and parallel equivalents, the Wheatstone bridge and modified nodal analysis of resistive networks; Thévenin, Norton and Jacobi’s maximum power transfer; RC and RL transients; complex impedance, series resonance and the ideal transformer; lossless and lossy transmission lines, Heaviside’s distortionless condition, reflections and input impedance for the Smith chart; and real, reactive and three-phase power, Fortescue’s symmetrical components and Gauss-Seidel load flow. Models are hand-written; NumPy solves the linear systems and SciPy computes the RLC step response.

Whether a line meets Heaviside’s distortionless condition \(R/L = G/C\).

On such a line the attenuation \(\alpha = \sqrt{RG}\) and the velocity \(1/\sqrt{LC}\) are the same at every frequency, so a pulse shrinks without changing shape.

  • C_per_m (float) – Shunt capacitance per unit length [F/m], positive.

engineeringkit.electrical_engineering.gauss_seidel_load_flow(Y, p_load, q_load, v_slack=1.0, tol=1e-08, max_iter=500, acceleration=1.0)[source]#

Gauss-Seidel load flow for a slack bus and PQ buses.

Bus 0 is the slack bus with fixed voltage. At every other bus the net injected complex power \(S_i = P_i + jQ_i\) is specified, and each sweep updates the bus voltages in turn,

\[V_i \leftarrow \frac{1}{Y_{ii}}\left(\frac{S_i^*}{V_i^*} - \sum_{k \ne i} Y_{ik} V_k\right),\]

using the newest value of every \(V_k\).

Parameters:

  • Y (array_like of complex) – Bus admittance matrix [pu], square, at least 2x2, nonzero diagonal; see admittance_matrix().

  • p_load (array_like) – Real [pu] and reactive [pu] power consumed at buses 1..n-1 (length n - 1); negative values are generation.

  • q_load (array_like) – Real [pu] and reactive [pu] power consumed at buses 1..n-1 (length n - 1); negative values are generation.

  • v_slack (complex, optional) – Slack-bus voltage [pu], nonzero.

  • tol (float, optional) – Stop when the largest voltage update is below this [pu], positive.

  • max_iter (int, optional) – Maximum number of sweeps, at least one.

  • acceleration (float, optional) – Over-relaxation factor [-] in \((0, 2)\); 1.4 to 1.6 is typical, 1 is plain Gauss-Seidel.

Returns:

Bus voltages, injected powers (bus 0 gives the slack power), sweep count, a convergence flag and the update history. No exception is raised on non-convergence; check converged.

Return type:

LoadFlowResult

Notes

Inputs are raw SI numbers with no dimensional metadata; see Electrical engineering: passive components and circuit responses. PV (voltage-controlled) buses are not modelled.

References

J. B. Ward and H. W. Hale, “Digital computer solution of power-flow problems,” Trans. AIEE Part III 75 (1956) 398-404.

Examples

>>> Y = admittance_matrix(2, [(0, 1, 0.1j)])
>>> r = gauss_seidel_load_flow(Y, [0.5], [0.0])
>>> r.converged, round(float(abs(r.voltages[1])), 4)
(True, 0.9987)

engineeringkit.electrical_engineering.input_impedance(z_load, z0, electrical_length)[source]#

Input impedance of a lossless line of electrical length \(\beta\ell\) ending in \(Z_L\).

The reflection coefficient rotates clockwise around the Smith chart, \(\Gamma_{in} = \Gamma_L e^{-2j\beta\ell}\), and the impedance is \(Z_{in} = Z_0(1 + \Gamma_{in})/(1 - \Gamma_{in})\), equivalent to \(Z_0 (Z_L + jZ_0\tan\beta\ell)/(Z_0 + jZ_L\tan\beta\ell)\).

Parameters:

  • z_load (complex or array_like) – Load impedance [ohm], finite with nonnegative real part.

  • z0 (float) – Characteristic impedance [ohm], positive.

  • electrical_length (float or array_like) – \(\beta\ell = 2\pi\ell/\lambda\) [rad], nonnegative.

Returns:

Input impedance [ohm]; very large where the line transforms the load into an open circuit.

Return type:

complex or ndarray of complex

Notes

Inputs are raw SI numbers with no dimensional metadata; see Electrical engineering: passive components and circuit responses.

References

P. H. Smith, “Transmission line calculator,” Electronics 12 (January 1939) 29-31.

Examples

>>> round(float(abs(input_impedance(100.0, 50.0, np.pi / 2))), 9)
25.0

engineeringkit.electrical_engineering.nodal_analysis(n_nodes, resistors, current_sources=(), voltage_sources=())[source]#

Solve a resistive DC network by modified nodal analysis.

Kirchhoff’s current law at each non-ground node, with Ohm’s law for every resistor, gives the conductance system \(G\mathbf{v} = \mathbf{i}\). Each ideal voltage source adds one unknown (its current) and one equation (its terminal voltage), the modified nodal system.

Parameters:

  • n_nodes (int) – Number of non-ground nodes, at least one. Nodes are numbered 1..n_nodes; node 0 is ground.

  • resistors (sequence of (int, int, float)) – (a, b, R) for each resistor between nodes a and b, with \(R\) [ohm] positive.

  • current_sources (sequence of (int, int, float), optional) – (a, b, I): a source driving current \(I\) [A] from node a through itself into node b.

  • voltage_sources (sequence of (int, int, float), optional) – (plus, minus, V): an ideal source holding \(v_{plus} - v_{minus} = V\) [V].

Returns:

Node voltages [V] (ground first), resistor currents from a to b [A], voltage-source currents out of the + terminal [A] and the KCL residual [A].

Return type:

NodalResult

Raises:

ValueError – For bad node indices or values, or if the network has no unique solution (a floating node or a loop of voltage sources).

Notes

Inputs are raw SI numbers with no dimensional metadata; see Electrical engineering: passive components and circuit responses.

References

G. Kirchhoff, “Ueber den Durchgang eines elektrischen Stromes durch eine Ebene, insbesondere durch eine kreisförmige,” Ann. Phys. 64 (1845) 497-514; C.-W. Ho, A. E. Ruehli and P. A. Brennan, “The modified nodal approach to network analysis,” IEEE Trans. Circuits Syst. 22 (1975) 504-509.

Examples

>>> r = nodal_analysis(2, [(1, 2, 1e3), (2, 0, 1e3)], voltage_sources=[(1, 0, 10.0)])
>>> [round(float(v), 6) for v in r.voltages]
[0.0, 10.0, 5.0]
