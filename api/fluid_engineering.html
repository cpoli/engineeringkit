engineeringkit.fluid_engineering#

Domain hub · History · Examples · API reference

Hydrostatic pressure, buoyancy and the force and centre of pressure on submerged planes; Bernoulli’s equation and continuity, with Pitot and Venturi meters; Reynolds number, Hagen-Poiseuille flow and its velocity profile, Darcy-Weisbach friction and minor losses, and the smooth, Nikuradse fully rough, Colebrook (scipy.optimize.brentq) and Swamee-Jain friction factors; Froude, Weber, Euler and Mach numbers and Buckingham’s Pi theorem by exact rational row reduction; Manning’s open-channel formula; Joukowsky’s water hammer with Korteweg’s wave speed; pump power, specific speed, NPSH and Thoma’s cavitation parameter; and Hardy Cross’s balancing of looped pipe networks.

engineeringkit.fluid_engineering: hydrostatics, pipe flow, similarity, open channels, transients, pumps and networks.

Stevin’s hydrostatic pressure and the force on submerged surfaces, Archimedes’s buoyancy; Bernoulli’s equation and continuity, with Pitot and Venturi meters; Reynolds’s regimes, Hagen-Poiseuille laminar flow, Darcy-Weisbach losses and the turbulent friction factors of Nikuradse, Colebrook and Swamee-Jain; Froude, Euler, Weber and Mach numbers and Buckingham’s Pi theorem by exact rational row reduction; Manning’s open-channel formula; Joukowsky’s water hammer with Korteweg’s wave speed; pump power, specific speed, NPSH and Thoma’s cavitation parameter; and Hardy Cross’s balancing of looped pipe networks. Models are hand-written closed forms; SciPy supplies root bracketing.

engineeringkit.fluid_engineering.buckingham_pi(variables, repeating=None)[source]#

Dimensionless groups of a set of variables by Buckingham’s Pi theorem.

The variables’ dimensions form a matrix \(D\) (base dimensions by variables). Every vector \(x\) with \(Dx = 0\) lists the exponents of one dimensionless product, and a basis of that null space has \(n - \operatorname{rank} D\) vectors. The repeating variables are placed first, so the exact row reduction pivots on them and each group contains exactly one other variable, raised to a positive power.

Parameters:

  • variables (mapping) – Variable name to its dimensions, itself a mapping from a base dimension ("M", "L", "T", "Θ", …) to an integer exponent; for example {"rho": {"M": 1, "L": -3}}. Dimensionless variables map to {}.

  • repeating (sequence of str, optional) – Names of the repeating variables, as many as the rank of the dimension matrix and dimensionally independent. Defaults to the first independent variables in variables order.

Returns:

Variables, dimension matrix and the integer exponents of each group.

Return type:

PiGroups

Notes

Inputs are raw SI numbers with no dimensional metadata; see Fluid engineering: flow regimes and signed quantities. The exponents come from exact rational arithmetic (integer_null_space()). The theorem fixes how many groups there are, not which ones: another choice of repeating variables gives products of these.

References

E. Buckingham, “On physically similar systems; illustrations of the use of dimensional equations,” Phys. Rev. 4 (1914) 345-376.

Examples

>>> pi = buckingham_pi(
...     {
...         "rho": {"M": 1, "L": -3},
...         "V": {"L": 1, "T": -1},
...         "D": {"L": 1},
...         "mu": {"M": 1, "L": -1, "T": -1},
...     }
... )
>>> pi.groups()
['rho^-1 V^-1 D^-1 mu^1']

engineeringkit.fluid_engineering.hardy_cross(resistances, loops, initial_flows, n=2.0, tol=1e-10, max_iter=200)[source]#

Balance the flows of a looped pipe network by Hardy Cross’s method.

Parameters:

  • resistances (array_like) – Resistance coefficient \(r_i\) of each pipe, so that \(h_i = r_i Q_i |Q_i|^{n-1}\) [s^n/m^(3n-1)], positive; for Darcy-Weisbach use pipe_resistance().

  • loops (array_like) – Loop matrix of shape (loops, pipes): +1 where the pipe’s reference direction runs clockwise round the loop, -1 where it runs anticlockwise, 0 where the pipe is not in the loop.

  • initial_flows (array_like) – Starting flow in each pipe [m^3/s], signed along its reference direction. It must satisfy continuity at every junction; the corrections preserve it.

  • n (float, optional) – Head-loss exponent, at least 1: 2 for Darcy-Weisbach with fixed friction factor, 1.852 for Hazen-Williams.

  • tol (float, optional) – Stop when the largest loop correction falls below this [m^3/s].

  • max_iter (int, optional) – Largest number of sweeps over all loops.

Returns:

Flows, head losses, loop residuals and the correction of each sweep.

Return type:

NetworkResult

Raises:

  • ValueError – If a loop has no pipes, or all its starting flows are zero so that the first correction is undefined.

  • RuntimeError – If the corrections do not fall below tol within max_iter sweeps.

Notes

Inputs are raw SI numbers with no dimensional metadata; see Fluid engineering: flow regimes and signed quantities. Loops are corrected one after another (Gauss-Seidel order), as Cross did by hand; a pipe shared by two loops receives both corrections, with opposite signs.

References

H. Cross, “Analysis of flow in networks of conduits or conductors,” Univ. Illinois Eng. Exp. Stn. Bull. 286 (1936).

Examples

One loop of two parallel pipes carrying 0.3 m³/s between two junctions:

>>> result = hardy_cross([1.0, 4.0], [[1, -1]], [0.15, 0.15])
>>> [round(float(q), 4) for q in result.flows]
[0.2, 0.1]
