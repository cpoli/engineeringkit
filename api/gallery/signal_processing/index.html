Examples#

Domain hub · History · Examples · API reference

This gallery walks through every public feature of engineeringkit.signal_processing, one breakthrough per script: Fourier series and the FFT, spectral estimation, sampling and quantization, digital filter design, optimal and adaptive filters, and wavelets.

Units, assumptions and numerical validation gives the validity limits. Each script is self-contained and can be run directly with python examples/signal_processing/<section>/<script>.py.

Sections#

  • spectral – Schuster’s periodogram, the Wiener-Khinchin theorem, Gabor’s short-time transform, Blackman and Tukey’s windows, Goertzel’s algorithm and Welch’s averaged periodogram.

  • fourier – Gibbs’s phenomenon and the Cooley-Tukey FFT.

  • wavelets – Haar’s wavelet.

  • filters – Butterworth’s filter, Hurewicz’s z-transform, Wiener’s optimal filter, the LMS adaptive filter, Kaiser’s FIR design and second-order sections.

  • sampling – Bennett’s quantization noise and Shannon’s sampling theorem.
