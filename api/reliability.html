engineeringkit.reliability: lifetimes, redundancy, structural reliability, risk and maintenance.

Halley’s life table and the bathtub hazard; Poisson failure counts; exponential and Weibull lifetimes with Epstein-Sobel confidence bounds and the Kaplan-Meier estimator for censored data; series, parallel and k-out-of-n systems with Birnbaum importance; Freudenthal’s stress-strength interference and the Hasofer-Lind index; Watson’s fault trees, WASH-1400 event trees and IEC 61508 safety integrity levels; Markov availability, Barlow-Proschan age replacement and Duane reliability growth. engineeringkit.reliability.age_replacement_cost_rate(T, preventive_cost, failure_cost, eta, beta)[source]#

Long-run cost per unit time of replacing a Weibull unit at age T or at failure.

Barlow and Proschan’s renewal-reward ratio, \(C(T) = [c_p R(T) + c_f F(T)] / \int_0^T R(t)\,dt\), with the Weibull integral \(\eta\,\Gamma(1+1/\beta)\,P(1/\beta, (T/\eta)^\beta)\) (\(P\) the regularised lower incomplete gamma function).

Parameters:

  • T (float or array_like) – Planned replacement age [s], positive.

  • preventive_cost (float) – Cost of a planned replacement [currency], nonnegative.

  • failure_cost (float) – Cost of a replacement after failure [currency], nonnegative.

  • eta (float) – Weibull scale [s], positive.

  • beta (float) – Weibull shape [-], positive.

Returns:

Cost rate [currency/s].

Return type:

float or ndarray

Notes

A finite optimum exists only if \(\beta > 1\) and \(c_f > c_p\); otherwise the cost rate keeps falling toward \(c_f/\mathrm{MTTF}\) (run to failure). Inputs are raw SI numbers with no dimensional metadata; see Reliability: distributions, independence and rate units.

References

R. E. Barlow and F. Proschan, Mathematical Theory of Reliability (Wiley, 1965), ch. 4.

Examples

>>> round(float(age_replacement_cost_rate(1e9, 1.0, 10.0, 1000.0, 1.0)), 4)
0.01

engineeringkit.reliability.event_tree_probability(initiating_frequency, failure_probabilities)[source]#

Frequencies of every sequence of an event tree with independent branch points.

After an initiating event of frequency \(f_0\), each of \(m\) safety functions succeeds or fails; a sequence’s frequency is \(f_0 \prod_j q_j^{\,o_j}(1-q_j)^{1-o_j}\).

Parameters:

  • initiating_frequency (float) – Initiating-event frequency [1/s] (or a probability), nonnegative.

  • failure_probabilities (array_like) – Failure-on-demand probability of each safety function [-], in [0, 1], in the order the tree asks them (at most 20).

Returns:

The \(2^m\) outcome rows (first function most significant, all successes first) and their frequencies.

Return type:

EventTreeResult

Notes

Real event trees prune branches that cannot matter and condition later functions on earlier ones; this helper keeps every branch and assumes independence. Inputs are raw SI numbers with no dimensional metadata; see Reliability: distributions, independence and rate units.

References

U.S. Nuclear Regulatory Commission, Reactor Safety Study (WASH-1400, NUREG-75/014, 1975).

Examples

engineeringkit.reliability.fault_tree_probability(tree, probabilities)[source]#

Probability of a fault tree’s top event from independent basic-event probabilities.

A tree is a basic-event name (str) or a gate tuple ("and", child, ...) / ("or", child, ...). If no basic event appears twice, gates combine directly: \(\prod p_i\) for AND and \(1 - \prod(1 - p_i)\) for OR. A repeated event makes the gate inputs dependent, so the top event is then evaluated exactly over every state of the basic events.

Parameters:

  • tree (str or tuple) – Fault-tree structure.

  • probabilities (mapping of str to float) – Probability of each basic event [-], in [0, 1].

Returns:

Top-event probability [-].

Return type:

float

Notes

Exact enumeration is limited to 20 distinct basic events. Inputs are raw SI numbers with no dimensional metadata; see Reliability: distributions, independence and rate units.

References

H. A. Watson, Launch Control Safety Study (Bell Telephone Laboratories, 1961); D. F. Haasl, “Advanced concepts in fault tree analysis,” System Safety Symposium (Seattle, 1965).

Examples

engineeringkit.reliability.hasofer_lind_index(limit_state, mean, std, tol=1e-08, max_iter=100)[source]#

Hasofer-Lind reliability index for independent normal variables (HL-RF iteration).

Each variable is standardised, \(u_i = (x_i - \mu_i)/\sigma_i\), and \(\beta\) is the distance from the origin to the nearest point of the failure surface \(g = 0\). The Rackwitz-Fiessler update \(u_{k+1} = [(\nabla g \cdot u_k - g)/|\nabla g|^2]\,\nabla g\) finds it, with central-difference gradients.

Parameters:

  • limit_state (callable) – \(g(x)\) for a 1-D array x; failure is \(g < 0\).

  • mean (array_like) – Means of the variables (their own units).

  • std (array_like) – Standard deviations, positive, same length as mean.

  • tol (float, optional) – Convergence tolerance on the design point in standard space [-].

  • max_iter (int, optional) – Maximum number of iterations.

Returns:

Index, design point, sensitivity vector and iteration count. The index is negative if the mean point already lies in the failure domain.

Return type:

HasoferLindResult

Raises:

ValueError – If the gradient vanishes or the iteration does not converge.

Notes

Inputs are raw SI numbers with no dimensional metadata; see Reliability: distributions, independence and rate units.

References

A. M. Hasofer and N. C. Lind, “Exact and invariant second-moment code format,” J. Eng. Mech. Div. ASCE 100 (1974) 111-121; R. Rackwitz and B. Fiessler, “Structural reliability under combined random load sequences,” Comput. Struct. 9 (1978) 489-494.

Examples

>>> result = hasofer_lind_index(lambda x: x[0] - x[1], [500.0, 400.0], [30.0, 40.0])
>>> round(result.beta, 4)
2.0

engineeringkit.reliability.kaplan_meier(times, failed=None)[source]#

Kaplan-Meier product-limit estimate of survival from censored life data.

At each distinct failure time \(t_j\), with \(n_j\) units at risk and \(d_j\) failures, \(\hat S(t) = \prod_{t_j \le t}(1 - d_j/n_j)\). Censored units leave the risk set without moving the curve; a unit censored at a failure time counts as at risk for that failure.

Parameters:

  • times (array_like) – Failure or censoring time of each unit [s], nonnegative.

  • failed (array_like of {0, 1} or bool, optional) – 1 where the unit failed, 0 where it was censored (removed or still running). Default: every unit failed.

Returns:

Failure times, survival estimate, risk-set sizes, failure counts and Greenwood standard errors.

Return type:

KaplanMeierResult

Notes

Inputs are raw SI numbers with no dimensional metadata; see Reliability: distributions, independence and rate units.

References

E. L. Kaplan and P. Meier, “Nonparametric estimation from incomplete observations,” J. Amer. Statist. Assoc. 53 (1958) 457-481.

Examples

>>> result = kaplan_meier([1, 2, 3, 4], [1, 0, 1, 1])
>>> np.round(result.survival, 4)

engineeringkit.reliability.mtbf_confidence_bounds(total_time, failures, confidence=0.9, time_terminated=False)[source]#

Two-sided chi-square confidence bounds on an exponential MTBF from a life test.

With \(r\) failures in total unit-time \(T\), the estimate is \(\hat\theta = T/r\) and \(2T/\theta\) is chi-square with \(2r\) degrees of freedom for a failure-terminated test (Epstein and Sobel). A time-terminated test uses \(2r + 2\) degrees of freedom for the lower bound.

Parameters:

  • total_time (float) – Total time on test summed over all units, censored ones included [s], positive.

  • failures (int) – Number of failures \(r\); at least one for a failure-terminated test, at least zero for a time-terminated one.

  • confidence (float, optional) – Two-sided confidence level [-], in (0, 1).

  • time_terminated (bool, optional) – True if the test stopped at a fixed time rather than at the \(r\)-th failure.

Returns:

(lower, upper) MTBF bounds [s]; upper is infinite for a time-terminated test with no failures.

Return type:

tuple of float

Notes

Inputs are raw SI numbers with no dimensional metadata; see Reliability: distributions, independence and rate units.

References

B. Epstein and M. Sobel, “Life testing,” J. Amer. Statist. Assoc. 48 (1953) 486-502.

Examples

>>> [round(b) for b in mtbf_confidence_bounds(10000.0, 5)]
[1092, 5076]
