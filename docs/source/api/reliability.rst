engineeringkit.reliability
==========================


.. include:: /_generated/nav/reliability.rst

Halley's life table and the bathtub hazard; Poisson failure counts;
exponential and Weibull lifetimes, Epstein-Sobel MTBF confidence bounds
(``scipy.stats.chi2``) and the Kaplan-Meier estimator for censored data;
series, parallel and k-out-of-n systems with Birnbaum importance;
Freudenthal's stress-strength interference and the Hasofer-Lind index; fault
trees with repeated events, event trees and IEC 61508 safety integrity
levels; Markov availability (``scipy.linalg.expm``), Barlow-Proschan age
replacement and Duane reliability growth.
